# AKai Website

Figma `ok2` visual converted into a responsive static website with interaction states.

## Files

- `index.html` - page markup
- `styles.css` - responsive layout and visual styling
- `app.js` - menu, modal, video dialog, reveal, and hover interactions

## Run Locally

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```
